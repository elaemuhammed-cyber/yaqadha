مشاريع وتصاميم قواعد البيانات

استعراض لتصاميم الجداول، العلاقات (ERD)، وهيكلة البيانات

1. نظام إدارة متجر (E-Commerce Database)

تصميم الجداول والعلاقات الأساسية لنظام متجر إلكتروني، يوضح الجداول الرئيسية (المستخدمين، المنتجات، والطلبات) وعلاقاتها (1-to-Many و Many-to-Many).

جدول العملاء (Customers)

Column Name Data Type Constraints Description
CustomerID INT Primary Key, Auto Increment معرف فريد للعميل
FullName VARCHAR(100) NOT NULL اسم العميل الكامل
Email VARCHAR(100) UNIQUE, NOT NULL البريد الإلكتروني

جدول الطلبات (Orders)

Column Name Data Type Constraints Description
OrderID INT Primary Key معرف الطلب
CustomerID INT Foreign Key (References Customers) معرف العميل صاحب الطلب
OrderDate DATETIME DEFAULT CURRENT_TIMESTAMP تاريخ ووقت الطلب
